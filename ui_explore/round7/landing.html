Set up

Two different things, so they are two different fields.

Adds one league by its Sleeper ID and leaves the rest of the list alone. For a league the account lookup does not return.

or

Looks up the account and shows what it returns: leagues you do not have yet, offered to add, and leagues you track that it no longer lists — which is how a league you have left is detected. It REPLACES nothing; you choose. No password: Sleeper does not use one.

Archiving and ordering are local conveniences. Sleeper has no concept of either, so nothing here changes anything on Sleeper.

Deleting a league

local purge · asks first

It removes, for that league only:

  • cached Sleeper snapshots for this league
  • its own Draft Sharks uploads — never the shared rankings pool
  • chat history and compaction backups
  • decisions, objectives and pinned messages
  • its format override, and any attachment scoped only to it

It never touches Sleeper. If you are still a member the league reappears, unsynced, the next time you sync the account.
